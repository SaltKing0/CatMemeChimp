# Contributing to MEMECHIMP

Thanks for helping the meme archive become a nicer little corner of the internet.

1. Fork the repository and create a focused branch.
2. Keep runtime code dependency-free unless a dependency solves a clear, documented problem.
3. Preserve keyboard navigation, reduced-motion behavior, and the 320 px mobile layout.
4. For every proposed image, document its source and your basis for redistribution. Do not add an image merely because it is available online.
5. Run `npm run check` and exercise the changed flow in a browser.
6. Open a pull request explaining the behavior before and after your change.

By contributing original code, you agree to license it under this repository's MIT license. Third-party assets remain under their own terms and must be identified in `THIRD_PARTY_NOTICES.md`.
